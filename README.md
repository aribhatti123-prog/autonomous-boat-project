# autonomous-boat-project
created as part of a group project. general purpose of the boat is to monitor water quality. Any code written by group members is explicitly commented as such. The project ran from 09/25 to 05/26

My primary contributions were:
- Creating the communication system (lora.h) in order to send live water quality data from the boat to a laptop at the base station
- Designing a data presentation system in python
- Integrating all subsystem code together, and optimising other group member's code
- Designing a control system, to allow the boat to navigate itself to predefined waypoints
